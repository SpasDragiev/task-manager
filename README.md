# Task Manager

A simple and elegant task management application built with HTML, CSS, and JavaScript. Organize your homework and tasks efficiently with features like categories, priorities, deadlines, and a beautiful dark/light theme toggle.

## Features

- ✅ **Add Tasks**: Create new tasks with title, category, priority, deadline, and description.
- 📝 **Edit Tasks**: Modify existing tasks inline.
- 🗑️ **Delete Tasks**: Remove tasks you no longer need.
- 🔍 **Search & Filter**: Find tasks by status, category, priority, or search term.
- 📅 **Sort Tasks**: Order tasks by deadline, priority, or creation date.
- 🌙 **Theme Toggle**: Switch between dark and light themes with a sun/moon icon in the top-left corner.
- 💾 **Persistent Storage**: Tasks are saved in your browser's local storage.
- 📊 **Dashboard**: View statistics like total, active, completed, and today's tasks.

## Technologies Used

- **HTML5**: Structure and semantic markup.
- **CSS3**: Styling with CSS variables for themes, gradients, and responsive design.
- **JavaScript (ES6+)**: Functionality, DOM manipulation, and local storage.

## How to Use

1. **Locally**: Open `index.html` in your web browser.
2. **Online**: Visit the deployed version on [Netlify](https://melodious-donut-071486.netlify.app).

### Adding a Task
- Fill in the form at the bottom: Title (required), Category, Priority, Deadline, Description.
- Click "Add Task" or press Enter.

### Managing Tasks
- Click the edit icon (✏️) to modify a task.
- Click the delete icon (🗑️) to remove a task.
- Use the checkboxes to mark tasks as completed.

### Filtering and Sorting
- Use the dropdowns above the task list to filter by status, category, or priority.
- Type in the search box to find tasks by title or description.
- Select a sort option to reorder tasks.

### Theme Toggle
- Click the sun (☀️) or moon (🌙) icon in the top-left corner to switch themes.
- Your preference is saved and remembered.
